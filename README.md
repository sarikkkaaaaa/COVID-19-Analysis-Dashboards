# 🦠 COVID-19 Analysis Dashboards using Power BI

This project includes two interactive Power BI dashboards focused on COVID-19 deaths and vaccination progress across different countries and continents.

I created these dashboards as part of my learning journey in data analytics to practise data visualization, explore real-world data, and present insights through interactive reports.

## 📊 Project Overview

The project is divided into two dashboards:

### 1. COVID-19 Deaths Analysis

This dashboard explores the global impact of COVID-19 through case and death statistics.

**Key features:**

* Total COVID-19 cases and deaths
* Overall death rate
* Daily deaths over time
* Top 10 countries by total deaths
* Comparison of population and total cases
* Deaths by continent
* Country-level deaths per million population
* Interactive continent and country filters

### 2. COVID-19 Vaccination Analysis

This dashboard focuses on vaccination progress and differences in vaccination coverage across countries.

**Key features:**

* Total vaccine doses administered
* People who received at least one dose
* Fully vaccinated population
* Countries with the highest number of doses
* Continent-wise vaccination comparison
* Cumulative vaccination trends over time
* GDP per capita versus vaccination coverage
* Interactive continent, country, and date filters

## 🛠️ Tools Used

* **Microsoft Power BI Desktop:** Dashboard development and visualization
* **Data Visualization:** Charts, KPI cards, maps, and interactive filters
* **Data Analysis:** Country-wise comparisons, trend analysis, and summary insights

## 💡 Key Learnings

Through this project, I practised:

* Building interactive dashboards in Power BI
* Selecting appropriate visuals to represent data
* Comparing statistics across countries and continents
* Identifying trends and patterns over time
* Presenting data through a clear and organized layout

## 🎯 Project Objective

The objective of this project is to use data visualization to explore the impact of COVID-19 and understand how mortality statistics and vaccination progress varied across countries and continents.
